# Bill Minder 💸

A simple, aesthetically pleasing bill & subscription reminder app for students.

## Features
- **Recurring Bills**: Never forget Netflix or Rent.
- **Smart Sorting**: Nearest due date first.
- **Color Alerts**: 🔴 Urgent (3 days), 🟡 Warning (7 days), 🟢 Safe.
- **Spending Overview**: Retro-style bar chart of monthly expenses.
- **Local Storage**: Data stays on your device.

## Setup
1. Open terminal in this folder.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the app.
4. Go to `http://localhost:5173` (or the URL shown).

## Tech Stack
- React
- TailwindCSS
- Canvas API (Native)
